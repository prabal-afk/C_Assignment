# C Programming – Practice Coding Platform Question Bank (Set 1)

Solutions to the C programming assignment, written in **C**.

- **Platform questions:** 30 problems across Modules 1–6 (LeetCode, HackerRank, HackerEarth)
- **VS Code questions:** 16 pattern-printing programs (Module 7)

## Repository Structure

```
Platform_Questions/   # Modules 1-6: <platform>_<problem>.c + <platform>_<problem>.docx
VSCode_Questions/     # Module 7: numbered .c programs
README.md
```

Each `.docx` in `Platform_Questions` contains the C code, the problem link and the screenshot of the successful submission.

## How to Compile and Run

```bash
gcc VSCode_Questions/08_centered_pyramid.c -o pyramid
./pyramid
```

The LeetCode and HackerRank function-style files contain only the function the site asks for (the judge supplies `main`), so they are meant to be pasted into the online editor rather than compiled on their own.

## File Naming

- Platform files: `<platform>_<problem_number_if_any>_<Problem_Name>` (e.g. `leetcode_344_Reverse_string.docx`)
- VS Code files: `<question_number>_<pattern_name>.c`
